\# React Student Portal



A React-based Student Management Portal built using React Router. The application provides separate pages for dashboard information, student details, courses, and student profile.



\## Features



\- Dashboard with student management summary

\- Students list displayed in a table

\- Courses list

\- Student profile page

\- Navigation using React Router

\- 404 error page for invalid routes

\- Simple and beginner-friendly React project structure



\## Technologies Used



\- React.js

\- JavaScript

\- React Router

\- HTML

\- CSS
